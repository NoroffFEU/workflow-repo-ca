# Project Title

The project is about implementing good practices when deploying, integrating and testing code syntax, updates and functionalities. Using several tools and features that allow us to perform consistent adjustments.

## Features

- Environment Variable (.env)
- Vitest (unit tests)
- Playwright (End to End tests)
- Github Actions
- Eslint (linting)
- Prettier (formating)
- Husky (commit hook)

## Prerequisites

- Node.js (v20+)
- npm

## Getting Started

### Installation

```bash
npm install
```

### Running the project

```bash
npm run dev
```

### Running Vitest Unit tests

```bash
npx run unit
```

### Running Playwright e2e tests

```bash
npx run e2e
```


## Environment Variables

Create a `.env` file in the root directory:

```bash
API_KEY=your-api-key-here
BASE_URL=https://example.com/api
```

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run unit` - Run tests
- `npm run lint` - Run ESLint
