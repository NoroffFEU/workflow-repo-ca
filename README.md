# Workflow CA

This project demonstrates automated workflows using Playwright for end-to-end (E2E) testing and Vitest for unit testing.  
It includes setup for Husky pre-commit hooks, lint-staged formatting, and environment variables for secure test credentials.

---

## 🛠️ Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/JKollerud/workflow-repo-ca-jk.git
cd workflow-repo-ca-jk
npm install
```
