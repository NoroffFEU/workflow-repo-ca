# Workflow repo for the CA

This project is a school project for the Workflow course. The purpose of the course is to learn formatting, linting, unit testing and e2e testing.

## Features

- ESLint code linting
- Prettier code formatting
- Husky pre-commit hooks
- Vitest unit testing
- Playwright E2E testing

## Prerequisities

- Node.js
- npm

## Getting started

### Installation

- Clone this repository:
  https://github.com/Elljens/workflow-repo-ca.git

- Install dependencies:

```bash
npm install
```

### Running the project

```bash
npm run dev
```

### Running tests

- Unit tests:

```bash
npm run unit
```

-E2E testing:

```bash
npm run e2e
```

## Environment Variables

Create a .env file in the root directory with your own test accaount details:

```
TEST_USER_EMAIL=
TEST_USER_PASSWORD=
```
