# Workflow repo for the CA

This project contains test with Vitest for testing the isActivePath function, the getUserName fuction and playwright test for valid login and navigation.

## Installing

1. Clone the repo:

```bash
git clone https://github.com/OJOverby/workflow-repo-ca.git
```

2. Install dependencies

```bash
npm install
```

### Dependencies

- eslint/js
- playwright
- dotenv
- eslint
- live-server
- prettier
- tailwindcss
- vitest
- jsdom

## Running

1. For running vitest

```bash
npm run test
```

2. For running e2e testing with playwright

```bash
npx playwright test
```
