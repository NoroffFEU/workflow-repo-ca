Workflow Repository CA

This project is part of my Workflow Course Assignment.
The goal was to "to enhance the quality of a website."
I also added some basic tests using Vitest (unit tests) and Playwright (end-to-end tests).

Here are the main commands I used during the project:
npm run dev # Start Tailwind watcher
npm run lint # Check all files with ESLint
npm run lint:fix # Fix ESLint issues automatically
npm run format # Format files with Prettier
npm run format:check # Check if files are formatted correctly
npm run test # Run unit tests (Vitest)
npm run test:e2e # Run end-to-end tests (Playwright)
