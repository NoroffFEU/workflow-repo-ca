# Workflow Course Assignment

This project focuses on setting up a front-end workflow with linting, formatting, unit tests, and end-to-end tests 

## Tools used

- **ESLint** - used to detect potential errors and enforce consistent code quality.
- **Prettier** - used to format code consistently across the project.
- **Husky** - used to run checks before comitting code.
- **lint-staged** - used to run linting and formatting only staged files.
- **vitest** - used for unit testing JavaScript utility functions.
- **Playwright** - used for end-to-end testing for user flows in browser.

## Getting started

### Install dependencies
```bash
npm install
```

### Run development server
```bash
npm run dev
```

### Run linting
```bash
npm run lint
```

### Run unit tests 
```bash
npm test
```

### Run end-to-end tests
```bash
npm run test:e2e
```
